# Linux 0.1.10 / Android 0.1.15

Совместимое обновление клиентов: меньше затрат CPU на MouseMorph и большее
окно приёма пакетов, пришедших не по порядку. Рабочие серверы не обновлялись
и не перезапускались. Для установки этих клиентов обновление сервера не нужно.

## Совместимость

Сохранены wire-формат MouseMorph v2, legacy, Noise IK, ключи, профили и MTU.
Старые и новые клиенты могут работать с действующими серверами одновременно.
Тесты обмена прежнего и нового Morph-кодеков проходят в обе стороны, для
всех профилей и размеров внутренней нагрузки 0–1430 байт.

Окно защиты от повторов увеличено с 1024 до 8192 пакетов, а его память
уменьшена с 8192 до 1032 байт. Оно расширяется только на обновлённой
принимающей стороне; у работающих серверов остаётся прежнее окно.

В локальном CPU-тесте время encode/decode MouseMorph уменьшилось на
13–17%. Это не замер скорости интернета и не обещание такого же прироста
пропускной способности VPN. Методика, результаты и границы проверки — в
[отчёте](PROTOCOL_PERFORMANCE_2026-09-10.md).

## Сборки

- Android 0.1.15, versionCode 16, Android 8.0/API 26 и новее, ABI
  `arm64-v8a` и `x86_64`. APK подписан существующим ключом проекта.
- Linux 0.1.10: AppImage и deb собраны на Ubuntu 22.04 с Rust 1.97.1;
  пакет Arch Linux `mousevpn 0.1.10-1` — на Arch с Rust 1.98.1.
- Контрольные суммы файлов опубликованы в `SHA256SUMS` рядом со сборками.

SHA-256 сертификата APK:

```text
19da2ecacc6e2f893342f91f079b46755de5d4c48219eadbb6009138f5d7b273
```

Обновление поверх старого APK сохраняет данные, если установленная версия
подписана тем же ключом. На рабочей станции Arch новый пакет уже установлен;
для запуска нового кода нужно обычным образом перезапустить клиент.

## Проверки

- 68 тестов общих библиотек, сервера и клиентских компонентов; Clippy без
  предупреждений в этих компонентах.
- 4 теста Linux GUI/helper и 10 Android unit-тестов.
- Android release lint: 0 ошибок, 10 предупреждений.
- Подпись APK, целостность ZIP и выравнивание 16 КиБ проверены.
- AppImage распакована: отдельный helper присутствует, конфликтующие
  библиотеки Wayland не включены. На Arch выполнен 15-секундный запуск
  с отдельными пустыми настройками, без сообщений об ошибках; VPN в этой
  проверке не подключался.

Сборки публикуются как предварительный выпуск: работа APK на физическом
Android-устройстве и сравнительные испытания VPN в реальной сети ещё
не проверены. Исходники серверных библиотек входят в коммит, но публикация
исходников и клиентских сборок не развёртывает их на рабочих серверах.
