# Концепт Android-интерфейса

Визуальный макет: [`android-ui-mockup-v1.png`](android-ui-mockup-v1.png).

## Главный экран

- Выбор текущего профиля и кнопка `+` находятся в верхней карточке.
- Одна большая кнопка питания переключает VPN между состояниями «включён» и «выключен».
- Под кнопкой показываются состояние соединения и краткая статистика.
- Настройка приложений в обход VPN остаётся отдельным действием внизу.

## Новая конфигурация

Кнопка `+` открывает отдельный экран с двумя полями:

1. Большое многострочное поле для зашифрованного ключа конфигурации `MV1.…`.
2. Пароль к ключу длиной не менее 8 символов.

После расшифровки имя, адрес сервера и криптографические ключи извлекаются автоматически. Пароль скрыт по умолчанию; рядом предусмотрена кнопка показа значения. Отдельных действий чтения и записи буфера обмена нет.

## Поведение

- Кнопка сохранения неактивна, пока обязательные поля не прошли проверку.
- После сохранения новый профиль выбирается автоматически, а пользователь возвращается на главный экран.
- Удаление и редактирование выбранного профиля доступны из меню карточки профиля, чтобы случайное удаление не находилось на главном экране.
- При подключении кнопка показывает промежуточное состояние и блокируется до успеха или ошибки.
