# Проверка MouseVPN — 5 сентября 2026

Проверены участки Linux/Android-клиентов, серверного протокола, админки и зависимости Rust. Это целевая проверка, а не полный аудит безопасности. Причина жалобы друга на открытие сайтов и пинг пока не воспроизведена: неизвестны сервер, режим и условия сравнения с Amnezia.

## Исправления

- **Изоляция серверных сессий.** Авторизованный клиент мог выбрать идентификатор чужой активной сессии и заменить запись в серверной таблице. Теперь коллизия отклоняется до изменения обоих индексов. Регрессионный тест с настоящим Noise-handshake воспроизводил проблему до исправления; после исправления проверяет сохранение обеих сессий и обычное переподключение. Расшифровка чужого трафика не продемонстрирована; подтверждённое последствие — нарушение доступности.
- **Обновление маршрутов MouseMorph.** Сервер повторял статический X25519/HKDF для каждого устройства при обновлении тегов, примерно раз в секунду, внутри цикла приёма UDP. Ключи теперь кэшируются; отзыв устройства удаляет и ключ, и маршруты. Проверены обновление тегов и отзыв. Это устраняет лишнюю работу; ускорение интернета или снижение пинга пока не измерено.
- **Android MTU.** Размер пакета теперь учитывает дополнительную обёртку MouseMorph и MTU физической сети, выбранной для UDP-сокета. Старый код при переподключении мог читать MTU самого VPN; нижняя граница 1280 также мешала уменьшению размера на узких IPv4-каналах. Например, при MTU физического интерфейса 1380 режим Morph ограничивает TUN до 1242. Это не обнаружение MTU всего интернет-маршрута: если Android не сообщает MTU, сохраняется серверное значение. [Документация Android](https://developer.android.com/reference/android/net/LinkProperties#getMtu()).

Форматы Noise-handshake, пакетов, профилей MV1 и административного API не изменены. Совместимость старых клиентов сохранена на уровне протокола; Android-исправление MTU требует нового APK.

## Что осталось

- **Повтор старого handshake:** по коду кэшируется только последний запрос устройства. Ранее перехваченный корректный HandshakeInit после другого переподключения потенциально может заменить активную сессию до подтверждения новых ключей клиентом. На рабочих серверах атака не выполнялась; необходим отдельный воспроизводящий тест и изменение жизненного цикла сессии с проверкой старых клиентов.
- **Зависимости GUI:** cargo-audit не нашёл записей в категории `vulnerabilities`, но сообщил `unsound` для glib 0.18.5 ([RUSTSEC-2024-0429](https://rustsec.org/advisories/RUSTSEC-2024-0429.html)) и 17 предупреждений о неподдерживаемых зависимостях. Это нельзя трактовать как отсутствие проблем. Обновление GTK/Tauri-зависимостей требует отдельной проверки совместимости.
- **Админка по HTTP:** публичный доступ сохранён. При обращении по обычному HTTP вне защищённого канала токен и выдаваемые конфигурации не защищены транспортным шифрованием. HTTPS позволяет оставить публичный доступ; в этой работе конфигурация админки не менялась. Диагностика с токенами выполнялась через SSH и loopback.
- **Строгая блокировка утечек:** очистка Linux-сетевых правил и закрытие Android TUN при остановке/переподключении не равны постоянной блокировке всего трафика вне VPN. Android Always-on с системной блокировкой соединений требует отдельной проверки сценариев.
- **Нагрузка handshake:** ограничение по адресу отправителя не заменяет глобальную защиту от распределённого/поддельного UDP-потока. Нагрузочная атака на рабочие серверы не выполнялась.
- **Подпись Android:** прежний keystore не найден. С согласия владельца создан новый внутренний debug-ключ, резервная копия `mousevpn-android-debug.keystore` в корне проекта, режим 0600. По отдельному явному пожеланию владельца этот внутренний ключ добавлен в локальный Git коммитом `6b328fd`; Gradle использует его непосредственно из корня проекта. Для предыдущего APK с другой подписью потребуется переустановка. Для публичного распространения нужна отдельная схема production-подписи.

## Проверки исходников

- 59 тестов Rust: server, admin-api, crypto, data-plane, transport, client-wire, linux-client, android-native — успешно.
- 10 JVM-тестов Android, включая 5 случаев выбора MTU — успешно как отдельно, так и в полноценной Gradle-сборке APK. `assembleRelease` и `lintRelease` завершились успешно: 0 ошибок lint, 10 предупреждений.
- `cargo clippy -p mousevpn-server --all-targets --no-deps`, форматирование серверного пакета и `git diff --check` — успешно.
- Проверка на настоящем Android-телефоне и измерение скорости с Amnezia пока не выполнены.
